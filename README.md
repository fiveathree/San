# 三國亂世錄

在瀏覽器玩的三國策略遊戲。參考光榮《三國志》系列（第四代起）的玩法，並採用第七代的「武將制」：可以選擇任何一名武將，從在野、武將、太守到主公，身分隨你的作為改變。

直接開 `index.html` 即可遊玩，不需安裝。

## 玩法

- **劇本**：190 年「群雄討董」、200 年「官渡之戰」。約 130 名武將，41 座城市。
- **在野**：拜訪、鍛鍊、討伐賊寇累積名聲；向所在城市的君主求仕；名聲達 200（或有同伴兩人及義勇兵一千）可在無主城市舉兵。
- **同伴**：在野時可邀請志同道合的在野人士結伴（最多 5 人），一同移動、討伐賊寇、招募義勇兵、鍛鍊；求仕或舉兵時一起加入。
- **一屏過**：所有畫面固定一屏，不用上下或左右捲動；清單按螢幕高度自動分頁；手機上地圖放大並可拖曳。
- **武將**：執行內政累積功績、晉升官位；功績高會被任命為太守；主公出兵時可能隨軍出陣；可下野。
- **太守**：統領本城武將，指派內政、出征、登用，亦可獨立。
- **主公**：向所有己方城市下令，任命太守、調動、輸送、賞賜、處置俘虜、委任內政。統一全部城市即勝利。
- **登用**：主公可派人登用全國任何城市的在野人士、俘虜，或忠誠低的敵將；太守限本城及相鄰城市。清單按成功率排序。
- **移動**：在地圖上點選目的地（可去的城市有紅圈）。
- **戰鬥**：回合制，攻擊、火計、混亂、單挑；單挑以「攻擊／防守／全力一擊」互相剋制。
- **時間**：每月 100 行動力；每月收金、七月收糧；武將依史實年份登場與逝世（可選延長壽命）；君主逝世由宗族或功臣繼承，玩家是主公時以繼承人身分繼續。
- 每月自動存檔，資料只存在瀏覽器 localStorage。

武將能力數值為本作自訂。本作與光榮特庫摩無關。
